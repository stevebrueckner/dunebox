# Dunebox

A backyard physics pit. Scoop sand, pack a keep, pour water, and dig down through the layers. Wet sand holds. Dry sand slumps. Buried toys turn up if you dig far enough.

## Run

```bash
npm install
npm run dev
```

Open the app and choose **Enter the pit**.

| Tool | What it does |
| --- | --- |
| Scoop | Fill the pail, then release to dump |
| Dig | Cut a hole and pile the spoil |
| Keep | Stamp a castle. Damp sand holds; dry or soaked sand fails |
| Water | Darken and soften a patch |
| Smash | Knock a wall down |
| Pick | Grab a toy and drop or bury it |
| Look | Orbit. Right-drag or WASD also move the camera |

The moisture slider soaks the whole pit. Sand color bands mark the surface, damp gold, deep pack, and bed earth.

Textures for the sand, wood, and grass are drawn in the browser. Social preview images (`public/og.jpg`, `public/x-banner.jpg`) and a few install screenshots are not in this repository.
